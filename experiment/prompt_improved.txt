Write the code for a random lunch menu recommender as a single index.html (HTML + CSS + JS inline) that I will publish on GitHub Pages.
A "Generate Lunch!" button picks a random item from a lunchMenu array with Math.floor(Math.random() * lunchMenu.length) and shows its name and icon.
Each item is written as { name: "Pizza", icon: "fas fa-pizza-slice" }.
Icons: load exactly Font Awesome Free 6.4.0 from https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css.
Use only icons that exist in the Free Solid set of that version. Pro-only icons
(for example `fa-bowl-hot`) and names that do not exist (for example `fa-pasta`, `fa-bowl`)
render as an empty box, which is the bug we are avoiding.
If there is no food icon for a dish, pick a generic Free one (`fa-bowl-food`, `fa-utensils`) instead of inventing a name.
The menu must contain exactly these 12 dishes: Pizza, Sushi, Burger, Salad, Tacos, Ramen, Sandwich, Pasta, Curry, Steak, Soup, BBQ.
